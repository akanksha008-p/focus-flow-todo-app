# Focus Flow 🪷

A simple and aesthetic To-Do List web app that helps you organize daily tasks and stay productive.

✨ Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Tasks saved using Local Storage
- Dark mode support
- Smooth animations
- Responsive design

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
